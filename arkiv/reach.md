## Who is it for, and would they use it?

GPU Pool is for developers using AI applications, students experimenting with open-source models, and researchers or small teams whose workloads exceed a single computer's memory. They can combine nearby Apple Silicon and NVIDIA machines to run larger models on hardware they already own, then access them through chat, or a proper harness like OpenCode.

Owners of idle GPUs can contribute capacity and earn inference credits for their own work. The reason to use GPU Pool is practical: access larger models without buying a higher-memory machine, and put spare compute to use. Arkiv makes available nodes and pools discoverable through expiring listings.

## Can they try it today, and will you keep building it after Mumbai?

Yes. Users can try the [app](https://gpupool-ethglobal.vercel.app) today: create an API key, or [create/join a pool](https://gpupool-ethglobal.vercel.app/getting-started) using the generated local setup command. The [setup guide](../README.md#set-up-and-use) covers API access and contributing a laptop.

Inference depends on a ready pool; users can check available models through the [model endpoint](https://ethglobal.yash-agrawal.dev/v1/models).

Our plan is to turn this project  into a startup and continue building after Mumbai. Our immediate priorities are marketing and on technical side - it is reliable recovery when nodes disconnect and easier onboarding so that setting up and using a pool takes very less manual work.
